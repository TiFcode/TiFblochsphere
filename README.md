# TiFblochsphere

Interactive browser-based Bloch sphere and qubit learning lab.

## Features

- Canvas-rendered sphere with X/Y/Z axes, latitude/longitude guides, state vector, θ and φ.
- Drag or tap the sphere, use sliders, named states, random states, and a Z rotation control.
- 25 selectable activities covering named states, measurements, coordinates, rotations, probability, phase, and challenges.
- Theory panel with the state equation, Bloch coordinates, measurement probabilities, and rotation explanation.

## Local run

```bash
python3 -m http.server 8125 --bind 0.0.0.0
```
